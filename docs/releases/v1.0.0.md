# Release v1.0.0

**Data:** 11/09/2026  
**Plataforma:** Windows 10 ou superior  
**Arquivo:** `RelatorioDespesaViagem-v1.0.0-Windows.zip`

## O que é

Primeira versão pública do Gerador de Relatórios de Despesa de Viagem (RDV).

Programa desktop para organizar comprovantes por projeto, extrair dados com OCR local ou IA e gerar o pacote de reembolso (Excel RDV, PDF resumo e comprovantes por categoria).

## Como instalar

1. Baixe o ZIP desta release
2. Extraia a pasta inteira para um local permanente (por exemplo `Documentos\RelatorioDespesaViagem`)
3. Abra `RelatorioDespesaViagem.exe`
4. Não apague a pasta `_internal` (pode estar oculta). Sem ela o programa não abre.

Envie sempre a pasta completa (ou o ZIP). Nunca só o `.exe`.

## O que entra nesta versão

- Projetos por viagem (contratante + natureza)
- Abas: Dados do projeto, Notas e relatório, Prévia visual
- OCR local gratuito (RapidOCR) e opcional Gemini / OpenAI / Claude
- Separação automática de PDFs com várias notas
- Conferência com zoom, recorte e cores de estado
- Detecção de duplicatas
- Relatório completo, por mês ou entre datas
- Modelo de cabeçalho, assinatura e categorias extras no RDV
- Tema claro/escuro
- Manual e Sobre no menu Ajuda

## Requisitos

- Windows 10 ou superior
- Internet só se for usar motor de IA ou consulta de CNPJ
- Excel ou compatível para abrir o `.xlsx` gerado

## Observações

- Preferências e chaves de API ficam em `data/` (criada no primeiro uso)
- Projetos ficam em `projetos/` ao lado do executável
- Chave gratuita do Gemini: https://aistudio.google.com/apikey
